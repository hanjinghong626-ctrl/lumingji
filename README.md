# 鹿鸣集 / LuMingJi

> 呦呦鹿鸣，食野之苹。我有嘉宾，鼓瑟吹笙。

来华留学生生活服务平台 —— 以三千年前的古礼，迎接远方来客。

## 关于

鹿鸣集取自《诗经·小雅》中的千年迎宾之歌，为来华留学生提供在青岛的生活信息、高校指南和社群连接。

## 技术栈

- Next.js 14 (App Router)
- Tailwind CSS
- next-intl（中/俄/英三语支持）

## 本地运行

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

## 语言支持

- 🇨🇳 中文 (zh)
- 🇷🇺 Русский (ru)
- 🇬🇧 English (en)

## 部署

部署在 Vercel，推送到 main 分支自动部署。
